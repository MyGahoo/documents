    模块介绍¶

    I 实时监测数据¶

    1. 当前功率¶

    显示实时骑行功率输出。

    颜色

    这是一个可以显示背景颜色的模块。可以在ConnectIQ应用中选择两种颜色序列样式。但是，用户无法自定义单独的颜色或区间范围。

    • Garmin样式：灰-蓝-绿-黄-橙-红-紫（区间1~区间7）
    • Wahoo样式：灰-深蓝-浅蓝-绿-黄-橙-红（区间1~区间7）

    平均功率指示器¶

    这是一个可以开启/关闭的设置，用于在当前功率模块内比较当前功率与平均功率。可以在ConnectIQ应用中设置。支持"箭头"显示模式。

    • "箭头"
      • 向上：高于平均功率
      • 向下：低于平均功率
      • 不显示：等于平均功率或骑行未开始


    2. 当前速度¶

    显示当前骑行速度。单位将与用户在Garmin Connect中的设置保持一致（kph/mph）。

    平均速度指示器¶

    这是一个可以开启/关闭的设置，用于在当前速度模块内比较当前速度与平均速度。可以在ConnectIQ应用中设置。有两种显示模式："箭头"和"背景"。

    • "箭头"
      • 向上：高于平均速度
      • 向下：低于平均速度
      • 不显示：等于平均速度或骑行未开始
    • "背景"
      • 红色：低于平均速度
      • 绿色：高于平均速度


    3. 当前心率¶

    显示实时心率数据。

    颜色

    这是一个可以设置背景颜色的模块。可以在ConnectIQ应用中选择两种颜色序列样式。但是，用户无法自定义单独的颜色或区间范围。

    • Garmin样式：灰-灰-蓝-绿-黄-红（<区间1，区间1~区间5）
    • Wahoo样式：灰-蓝-绿-黄-橙-红（<区间1，区间1~区间5）

    平均心率指示器¶

    这是一个可以开启/关闭的设置，用于在当前心率模块内比较当前心率与平均心率。可以在ConnectIQ应用中设置。支持"箭头"显示模式。

    • "箭头"
      • 向上：高于平均心率
      • 向下：低于平均心率
      • 不显示：等于平均心率或骑行未开始


    4. 当前踏频¶

    显示实时踏频值。

    平均踏频指示器¶

    这是一个可以开启/关闭的设置，用于在当前踏频模块内比较当前踏频与平均踏频。可以在ConnectIQ应用中设置。支持"箭头"显示模式。

    • "箭头"

      • 向下：低于平均踏频
      • 不显示：等于平均踏频或骑行未开始


    5. 当前海拔¶

    显示当前海拔。单位将与用户在Garmin Connect中的设置保持一致（m/ft）。


    6. 当前坡度*¶

    显示当前坡度。
    *Garmin官方未提供数据接口，因此计算的数据可能存在不准确或错误

    颜色

    这是一个可以显示背景颜色的模块。颜色根据相应的坡度变化，但用户无法自定义颜色或坡度范围。

    示例
    坡度范围 < 0.5% 0.5%~3.99% 4%~7.99% 8%~11.99% 12%~19.99% > 20%

    37. W'Balance*¶

    显示当前活动的W'Balance（W prime balance）。这需要预先定义CP（临界功率）和W'（W Prime）才能工作。有关科学解释，会有大量文章或视频来解释它是什么。

    在活动期间，此字段可以是绿色或红色。当为绿色时，表示您当前的功率低于CP，换句话说，您正在"恢复"。反之，当为红色时，表示您正在消耗。

    当前的数学模型使用Froncioni / Clarke的微分模型：

    W′bal = W′bal + (CP - P) * (W′ - W′bal) / W′ 当 P > CP

    W′bal = W′bal + (CP - P) 当 P < CP

    *Garmin官方未提供数据接口，因此计算的数据可能存在不准确或错误

    56. 风*¶

    显示当前风速和相对/绝对风向。

    *Garmin官方未提供数据接口，因此计算的数据可能存在不准确或错误

    风速单位¶

    • m/s：米/秒
    • KPH：公里/小时
    • MPH：英里/小时
    • Beaufort scale：风力等级，0~12级

    风速等级¶

    风速等级由箭头数量指示，不同数量对应的风速如下图所示。当选择的风速单位不是m/s时，箭头数量仍将根据正确的风速而非显示的数字进行计算。

    绝对/相对风向¶

    • 绝对风向：天气预报中给出的风向，与骑行方向无关
    • 相对风向：当前骑行方向与风向的相对角度。例如，如果向西行驶，绝对风向从北向南，则相对风向从右向左。

    风向颜色¶

    显示相对风向时，箭头根据风角度着色。红色表示逆风（相对风从左前45°到右前45°）；绿色表示顺风（相对风从左后45°到右后45°）；黑色表示侧风。

    配置¶

    风模块需要在ConnectIQ应用中配置以获得最佳显示效果。详情请参考天气配置模块。

    IX 虚拟LED¶

    虚拟LED可以配置在屏幕边缘周围。用户可以使用不同位置的LED显示不同信息。

    虚拟LED的两个水平字段（上和下）现在支持状态栏。状态栏中的图标从左到右分别是：电池、GPS信号状态、手机连接状态（条件性）、未读消息（条件性）、时间。

    当手机未连接到Garmin Edge时，"蓝牙"图标将不显示。当没有未读消息时，未读消息图标将不显示。当未读消息数量大于9时，将始终显示"9+"而不是实际数字。

    图像 状态 描述
    QUALITY_NOT_AVAILABLE GPS不可用
    QUALITY_LAST_KNOWN 位置基于最后已知的GPS定位
    QUALITY_POOR 位置通过较差的GPS定位计算。只有2-D GPS定位可用，可能由于跟踪的卫星数量有限
    QUALITY_USABLE 位置通过可用的GPS定位计算。3-D GPS定位可用，具有边际HDOP（水平精度稀释）
    QUALITY_GOOD 位置通过良好的GPS定位计算。3-D GPS定位可用，具有良好到优秀的HDOP（水平精度稀释）

    平均速度指示器¶

    虚拟LED显示当前速度与平均速度的关系，红色表示落后（低于平均值），蓝色表示领先（高于平均值）。

    每个LED代表10%的领先或落后，如下表所示。表格以领先为例；落后遵循相同原理。

    示例 含义
    等于平均速度
    当前领先 < 10%
    10% < 当前领先 < 20%
    当前领先 > 20%

    平均功率指示器¶

    虚拟LED显示当前功率与平均功率的关系，颜色含义与上述相同，但每个LED代表20%的领先或落后。表格以领先为例；落后遵循相同原理。

    示例 含义
    等于平均功率
    当前领先 < 20%
    20% < 当前领先 < 40%
    当前领先 > 40%

    左右平衡指示器¶

    虚拟LED显示当前踩踏功率的左右平衡。每个LED代表一侧5%的偏移。表格以右偏踩踏为例；相反情况遵循相同原理。

    此外，如果接收到的左右平衡值为100-0或0-100，将显示错误状态。这种情况通常由于双侧功率计的一侧断开连接或首次踩踏时的瞬间力量而发生。

    示例 L - R
    50% - 50%
    45~50% - 50~55%（不包括55%）
    40~45% - 55~60%（不包括60%）
    ≤40% - ≥60%
    0%-100%（或100%-0%）

    X 配置说明¶

    本章节按设置页的顺序，逐项说明每个设置的作用与影响范围。标题方框内的编号对应该项在设置页中的位置。

    影响范围中涉及的字段编号，请参阅前述各字段的说明。

    ActivationCode（激活码）¶

    在设置页中输入激活码以解锁完整功能。

    作用：

    • 输入您购买后获得的激活码，激活 MyGahoo Pro 全部功能

    配置建议：

    • 激活码与设备绑定，每个设备需要独立的激活码
    • 如果在同一个设备上登录不同的账号，激活码不会改变
    • 如果更换设备，需要重新获取激活码

    [1.1] FTP (瓦)¶

    FTP 是骑手可以长期维持的临界功率值，是计算多项训练指标的基础参数。

    作用：

    • 设定骑手的功能性阈值功率，用于计算功率区间、功重比、NP、TSS、IF 等训练指标

    影响范围：

    • 当前功率字段的区间颜色划分
    • 功重比字段的计算
    • NP字段相关的 TSS 计算
    • IF字段的计算

    配置建议：

    • 建议使用 20 分钟实测功率或 CP（临界功率）作为输入值
    • FTP 需要与 Garmin 个人资料中的体重配合使用来计算功重比
    • 修改 FTP 后，TSS、IF 等指标会基于已记录的 NP 数据重新计算

    [1.2] OpenWeather API密钥（现在支持所有设备）¶

    用于连接 OpenWeather 服务，获取实时天气数据。

    作用：

    • 输入 OpenWeather API 密钥，使应用能够获取在线天气数据

    影响范围：

    • 空气温度字段
    • 体感温度字段
    • 湿度字段

    配置建议：

    • 需要自行在 OpenWeather 官网注册并获取 API 密钥
    • 设备需要通过手机连接网络
    • 需要已获取 GPS 定位（室内可能无法获取天气数据）

    [1.3] 虚拟页面翻页模式¶

    控制用户如何在已选择的布局中切换不同的数据块位置。

    作用：

    • 设置是否启用虚拟翻页功能，以及使用按钮还是触摸操作

    配置建议：

    • 关闭：禁用虚拟翻页，触摸屏幕会唤起系统原生菜单
    • 快速按钮模式：连续按动「上下上下」按钮组合（间隔 2 秒内）向后翻页，仅支持向后翻页
    • 触摸模式：点击屏幕下半部分左侧向右翻页，右侧向左翻页，适用于触屏设备
    • 触摸和快速按钮模式：同时启用触摸和按钮两种模式

    [1.4] 布局¶

    选择屏幕上数据块的排列方式和数量。

    作用：

    • 决定屏幕上显示的数据块数量和排列模板

    [2.4] 使用相对风向 (箭头根据移动方向改变)¶

    [2.10] [W'Bal] CP (W) / W' (J) / 显示模式 / 算法¶

    这一组设置共同控制 W'Balance 功能的计算和显示。

    CP（临界功率）¶

    骑手可以长时间维持的功率上限，也是 W'Balance 消耗/恢复的判定阈值。

    作用：

    • W'Balance字段的消耗/恢复判定
    • 当功率高于 CP 时消耗 W'Balance，低于 CP 时恢复 W'Balance

    配置建议：

    • 如果明确知道自己的CP则设置为CP，如果不知道则可以近似设置为FTP

    WPRIME（W'能量储备）¶

    骑手可以在 CP 以上输出的总能量储备。

    配置建议：

    • 默认值约为 10000 焦耳（10 千焦）
    • 有经验的骑手通常设置在 15000~20000 焦耳范围

    显示模式¶

    设置 W'Balance 数据的显示方式。

    作用：

    • 选择以百分比还是千焦耳显示，以及是否带颜色

    配置建议：

    • 百分比：显示剩余百分比，带颜色（绿色=恢复，红色=消耗）
    • 千焦：显示剩余能量值，带颜色
    • 百分比 (无颜色)：显示剩余百分比，无颜色
    • 千焦 (无颜色)：显示剩余能量值，无颜色

    算法¶

    选择 W'Balance 的计算模型。

    配置建议：

    • 积分算法：消耗和恢复都较慢、更平滑，适合耐力骑行
    • 微分算法：消耗快、恢复也快，响应更及时，适合间歇训练

    [2.11] 启用右上标题偏移 (避免雷达图标重叠)¶

    设置右上角标题是否向右偏移，避免与雷达图标重叠。

    配置建议：

    • 仅在使用 Garmin 雷达功能时需要开启
    • 默认关闭即可

    [2.12] 变速图 - 1X单盘模式¶

    设置齿比图是否显示为 1X 单盘模式。

    配置建议：

    • 开启后：齿比图将仅显示飞轮图表，而不显示牙盘图表
    • 关闭后：默认同时显示飞轮和牙盘图表

    [3.1-3.4] 左LED / 右LED / 上LED / 下LED¶

    虚拟 LED 可以配置在屏幕的四条边缘，用于显示不同类型的数据。

    作用：

    • 在屏幕边缘显示功率/心率区间、平均指示器、左右平衡或状态栏

    影响范围：

    • 功率区间 LED：影响当前功率、各平均功率字段的区间可视化
    • 心率区间 LED：影响当前心率字段的区间可视化
    • 平均指示器 LED：影响平均数据的领先/落后显示
    • 左右平衡 LED：影响左右平衡字段的可视化
    • 状态栏 LED：显示电池、GPS、蓝牙连接、时间等状态图标

    配置说明：

    位置 可选择的内容
    左侧 LED（3.1） 关闭 / 3秒功率区间 / 功率区间 / 心率区间 / 平均速度指示器 / 平均功率指示器
    右侧 LED（3.2） 关闭 / 3秒功率区间 / 功率区间 / 心率区间 / 平均速度指示器 / 平均功率指示器
    顶部 LED（3.3） 关闭 / 状态栏 / 3秒功率区间 / 功率区间 / 心率区间 / 平均速度指示器 / 平均功率指示器 / 左右功率平衡 / 3秒左右平衡
    底部 LED（3.4） 关闭 / 状态栏 / 3秒功率区间 / 功率区间 / 心率区间 / 平均速度指示器 / 平均功率指示器 / 左右功率平衡 / 3秒左右平衡

    配置建议：

    • 关闭：该边不显示 LED
    • 状态栏：仅顶部和底部可用，显示电池图标、GPS 信号状态、手机连接状态、未读消息数量、当前时间
    • 功率/心率区间：7 个 LED 显示各功率/心率区间的数量分布
    • 平均指示器：蓝色表示领先，红色表示落后
    • 左右平衡：顶部和底部 LED 专用，每个 LED 代表一侧 5% 的偏移

    左右平衡 LED 错误状态

    如果左右平衡值显示为 100-0 或 0-100，将显示错误状态。这通常是由于双侧功率计的一侧断开连接或首次踩踏时的瞬间力量导致的。

    启用页面¶

    控制是否启用第 2 页和第 3 页。

    影响范围：

    • 页面切换功能是否可用
    • 单页模式下不显示页码

    配置建议：

    • 第 1 页始终启用且不可关闭
    • 启用多页后，用户可以通过虚拟滚动或触摸操作切换页面
    • 每个页面可独立设置 MainBlock 和左右两侧的数据块类型

    页面与布局的关系

    多页面设置允许用户配置多组不同的数据块组合，每组使用相同的布局样式但选择不同的数据块显示。
