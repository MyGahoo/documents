    Introducción a los Módulos¶

    I Datos de Monitoreo en Tiempo Real¶

    1. Potencia Actual¶

    Muestra la salida de potencia de ciclismo en tiempo real.

    Colores

    Este es un módulo que puede mostrar colores de fondo. Puedes elegir entre dos estilos de secuencia de colores en la aplicación ConnectIQ. Sin embargo, los usuarios no pueden personalizar colores individuales o rangos de zonas.

    • Estilo Garmin: Gris-Azul-Verde-Amarillo-Naranja-Rojo-Morado (Zona 1~Zona 7)
    • Estilo Wahoo: Gris-Azul oscuro-Azul claro-Verde-Amarillo-Naranja-Rojo (Zona 1~Zona 7)

    Indicador de Potencia Promedio¶

    Este es un parámetro de encendido/apagado utilizado para comparar la potencia actual con la potencia promedio dentro del módulo de potencia actual. Se puede configurar en la aplicación ConnectIQ. Admite el modo de visualización "Flecha".

    • "Flecha"
      • Hacia arriba: Superior a la potencia promedio
      • Hacia abajo: Inferior a la potencia promedio
      • Sin visualización: Igual a la potencia promedio o ciclismo no iniciado


    2. Velocidad Actual¶

    Muestra la velocidad actual de ciclismo. La unidad coincidirá con tu configuración de Garmin Connect (kph/mph).

    Indicador de Velocidad Promedio¶

    Este es un parámetro de encendido/apagado utilizado para comparar la velocidad actual con la velocidad promedio dentro del módulo de velocidad actual. Se puede configurar en la aplicación ConnectIQ. Hay dos modos de visualización: "Flecha" y "Fondo".

    • "Flecha"
      • Hacia arriba: Superior a la velocidad promedio
      • Hacia abajo: Inferior a la velocidad promedio
      • Sin visualización: Igual a la velocidad promedio o ciclismo no iniciado
    • "Fondo"
      • Rojo: Inferior a la velocidad promedio
      • Verde: Superior a la velocidad promedio


    3. Frecuencia Cardíaca Actual¶

    Muestra datos de frecuencia cardíaca en tiempo real.

    Colores

    Este es un módulo que puede establecer colores de fondo. Puedes elegir entre dos estilos de secuencia de colores en la aplicación ConnectIQ. Sin embargo, los usuarios no pueden personalizar colores individuales o rangos de zonas.

    • Estilo Garmin: Gris-Gris-Azul-Verde-Amarillo-Rojo (<Zona 1, Zona 1~Zona 5)
    • Estilo Wahoo: Gris-Azul-Verde-Amarillo-Naranja-Rojo (<Zona 1, Zona 1~Zona 5)

    Indicador de Frecuencia Cardíaca Promedio¶

    Este es un parámetro de encendido/apagado utilizado para comparar la frecuencia cardíaca actual con la frecuencia cardíaca promedio dentro del módulo de frecuencia cardíaca actual. Se puede configurar en la aplicación ConnectIQ. Admite el modo de visualización "Flecha".

    • "Flecha"
      • Hacia arriba: Superior a la frecuencia cardíaca promedio
      • Hacia abajo: Inferior a la frecuencia cardíaca promedio
      • Sin visualización: Igual a la frecuencia cardíaca promedio o ciclismo no iniciado


    4. Cadencia Actual¶

    Muestra el valor de cadencia en tiempo real.

    Indicador de Cadencia Promedio¶

    Este es un parámetro de encendido/apagado utilizado para comparar la cadencia actual con la cadencia promedio dentro del módulo de cadencia actual. Se puede configurar en la aplicación ConnectIQ. Admite el modo de visualización "Flecha".

    • "Flecha"
      • Hacia arriba: Superior a la cadencia promedio
      • Hacia abajo: Inferior a la cadencia promedio
      • Sin visualización: Igual a la cadencia promedio o ciclismo no iniciado


    5. Altitud Actual¶

    Muestra la altitud actual. La unidad coincidirá con tu configuración de Garmin Connect (m/ft).


    6. Pendiente Actual*¶

    Muestra la pendiente actual.
    *Como Garmin no proporciona oficialmente una interfaz de datos, los datos calculados pueden ser inexactos o incorrectos

    Colores

    Este es un módulo que puede mostrar colores de fondo. Los colores cambian según la pendiente correspondiente, pero los usuarios no pueden personalizar los colores o rangos de pendiente.

    Ejemplo
    Rango de Pendiente < 0,5% 0,5%~3,99% 4%~7,99% 8%~11,99% 12%~19,99% > 20%

    35. NP™ (Potencia Normalizada)*¶

    Muestra la potencia normalizada de la actividad actual.

    Riesgo de Pérdida de Datos

    "Re-agregar" el campo MyGahoo durante una actividad o entrar en otros modos de ciclismo borrará los datos de este módulo. (Sin embargo, la actividad registrada por Garmin mismo no se verá afectada; solo MyGahoo comenzará a acumular estos datos desde cero).

    ™Potencia Normalizada (NP) y Puntuación de Estrés de Entrenamiento (TSS) son marcas registradas de Peaksware, LLC.
    *Como Garmin no proporciona oficialmente una interfaz de datos, los datos calculados pueden ser inexactos o incorrectos


    36. TSS™ (Puntuación de Estrés de Entrenamiento)*¶

    Muestra la Puntuación de Estrés de Entrenamiento de la actividad actual.

    Riesgo de Pérdida de Datos

    "Re-agregar" el campo MyGahoo durante una actividad o entrar en otros modos de ciclismo y luego regresar al modo actual borrará los datos de este módulo. (Sin embargo, la actividad registrada por Garmin mismo no se verá afectada; solo MyGahoo comenzará a acumular estos datos desde cero).

    ™Potencia Normalizada (NP) y Puntuación de Estrés de Entrenamiento (TSS) son marcas registradas de Peaksware, LLC.
    *Como Garmin no proporciona oficialmente una interfaz de datos, los datos calculados pueden ser inexactos o incorrectos

    37. W'Balance*¶

    Muestra el W'Balance (W Prime Balance) de la actividad actual. Para que esto funcione, CP (Critical Power) y W' (W Prime) deben estar predefinidos. Para explicaciones científicas, hay muchos artículos y videos que explican qué es esto.

    Durante la actividad, este campo será verde o rojo. Cuando está verde, significa que tu potencia actual está por debajo de CP, en otras palabras, estás "recuperándote". Por el contrario, cuando está rojo, significa que te estás agotando.

    El modelo matemático actual utiliza el modelo diferencial de Froncioni / Clarke:

    W′bal = W′bal + (CP - P) * (W′ - W′bal) / W′ cuando P > CP

    W′bal = W′bal + (CP - P) cuando P < CP

    *Como Garmin no proporciona oficialmente una interfaz de datos, los datos calculados pueden ser inexactos o incorrectos


    38. Tiempo Restante del Paso de Entrenamiento Actual¶

    Muestra el tiempo de cuenta regresiva restante para el paso de entrenamiento actual. Solo es efectivo cuando se ha iniciado un entrenamiento estructurado de Garmin (Workout). Si el paso de entrenamiento actual no tiene límite de tiempo, no se mostrarán datos.



    39. IF™ (Factor de Intensidad)*¶

    Muestra el Factor de Intensidad de la actividad actual, utilizado para evaluar el nivel de intensidad de esta sesión de entrenamiento.

    ™Factor de Intensidad (IF) es una marca registrada de Peaksware, LLC.
    *Como Garmin no proporciona oficialmente una interfaz de datos, los datos calculados pueden ser inexactos o incorrectos

    VIII Información Ambiental¶

    53. Reloj¶

    Muestra la hora actual.


    54. Batería¶

    Muestra el nivel actual de batería en porcentaje.


    55. Temperatura (Sensor)¶

    Muestra la temperatura actual en grados Celsius o Fahrenheit. Se actualiza cada 5 minutos. La frecuencia no puede ser mayor debido a las limitaciones de Garmin.


    56. Viento*¶

    Muestra la velocidad del viento actual y la dirección del viento relativa/absoluta.

    *Como Garmin no proporciona oficialmente una interfaz de datos, los datos calculados pueden ser inexactos o incorrectos

    Unidades de Velocidad del Viento¶

    • m/s: Metros por segundo
    • KPH: Kilómetros por hora
    • MPH: Millas por hora
    • Escala de Beaufort: Escala de fuerza del viento, niveles 0~12

    Niveles de Velocidad del Viento¶

    Los niveles de velocidad del viento se muestran por el número de flechas, y las velocidades de viento correspondientes a diferentes números se muestran en la figura a continuación. Si la unidad de velocidad del viento elegida no es m/s, el número de flechas se calculará basándose en la velocidad del viento correcta, no en el número mostrado.

    Dirección del Viento Absoluta/Relativa¶

    • Dirección absoluta: Dirección del viento como se indica en los informes meteorológicos, independiente de la dirección de conducción
    • Dirección relativa: Ángulo relativo entre la dirección de conducción actual y la dirección del viento. Por ejemplo, si conduces hacia el oeste y la dirección absoluta del viento es de norte a sur, entonces la dirección relativa del viento es de derecha a izquierda.

    Colores de Dirección del Viento¶

    Al mostrar la dirección relativa del viento, las flechas se colorearán según el ángulo del viento. El rojo indica viento en contra (viento relativo de 45° frontal izquierdo a 45° frontal derecho), el verde indica viento a favor (viento relativo de 45° trasero izquierdo a 45° trasero derecho), y el negro indica viento lateral.

    Configuración¶

    El módulo de viento requiere configuración en la aplicación ConnectIQ para efectos de visualización óptimos. Ver el módulo Configuración del Clima para más detalles.


    57. Temperatura (OpenWeather)*¶

    Muestra la temperatura actual en grados Celsius o Fahrenheit. La fuente de datos es OpenWeather, por lo que se requieren configuraciones válidas de API de OpenWeather para habilitar los datos.


    58. Temperatura Sensación (OpenWeather)*¶

    Muestra la temperatura sensación actual en grados Celsius o Fahrenheit. La fuente de datos es OpenWeather, por lo que se requieren configuraciones válidas de API de OpenWeather para habilitar los datos.


    59. Humedad (OpenWeather)*¶

    Muestra la humedad relativa actual en porcentaje. La fuente de datos es OpenWeather, por lo que se requieren configuraciones válidas de API de OpenWeather para habilitar los datos.


    60. Hora del Amanecer¶

    Muestra la hora del amanecer del día. La fuente de datos es el servicio meteorológico integrado de Garmin, requiere que el dispositivo soporte funciones meteorológicas (530/830 y modelos más nuevos) y que se haya adquirido ubicación GPS.


    61. Hora del Atardecer¶

    Muestra la hora del atardecer del día. La fuente de datos es el servicio meteorológico integrado de Garmin, requiere que el dispositivo soporte funciones meteorológicas (530/830 y modelos más nuevos) y que se haya adquirido ubicación GPS.


    IX LED Virtual¶

    Los LEDs virtuales pueden configurarse alrededor de los bordes de la pantalla. Los usuarios pueden usar LEDs en diferentes posiciones para mostrar diferente información.

    Los dos campos horizontales (superior e inferior) de los LEDs virtuales ahora soportan barras de estado. Los iconos de la barra de estado son de izquierda a derecha: batería, estado de señal GPS, estado de conexión telefónica (condicional), mensajes no leídos (condicional), hora.

    Si el teléfono no está conectado al Garmin Edge, el icono "Bluetooth" no se mostrará. Si no hay mensajes no leídos, el icono de mensajes no leídos no se mostrará. Si el número de mensajes no leídos es mayor que 9, "9+" siempre se mostrará en lugar del número real.

    Imagen Estado Descripción
    QUALITY_NOT_AVAILABLE GPS no disponible
    QUALITY_LAST_KNOWN Posición basada en la última posición GPS conocida
    QUALITY_POOR Posición por cálculo de posición GPS pobre. Solo posición GPS 2-D disponible, posiblemente debido al número limitado de satélites rastreados
    QUALITY_USABLE Posición por cálculo de posición GPS utilizable. Posición GPS 3-D disponible con HDOP marginal (dilución de precisión horizontal)
    QUALITY_GOOD Posición por buen cálculo de posición GPS. Posición GPS 3-D disponible con HDOP bueno a excelente (dilución de precisión horizontal)

    El LED virtual muestra el número y colores de cada zona (el ejemplo a continuación tiene el estilo de color establecido en estilo Garmin)

    El LED virtual muestra el número y colores de cada zona (el ejemplo a continuación tiene el estilo de color establecido en estilo Garmin)

    Indicador de Velocidad Promedio¶

    El LED virtual muestra la relación entre la velocidad actual y la velocidad promedio, el rojo indica retraso (por debajo del promedio) y el azul indica adelanto (por encima del promedio).

    Cada LED representa 10% de adelanto o retraso, como se muestra en la tabla a continuación. La tabla usa adelanto como ejemplo, el retraso sigue el mismo principio.

    Ejemplo Significado
    Igual a la velocidad promedio
    Adelanto actual < 10%
    10% < Adelanto actual < 20%
    Adelanto actual > 20%

    Indicador de Potencia Promedio¶

    El LED virtual muestra la relación entre la potencia actual y la potencia promedio, los significados de los colores son los mismos que arriba, pero cada LED representa 20% de adelanto o retraso. La tabla usa adelanto como ejemplo, el retraso sigue el mismo principio.

    Ejemplo Significado
    Igual a la potencia promedio
    Adelanto actual < 20%
    20% < Adelanto actual < 40%
    Adelanto actual > 40%

    Indicador de Balance Izquierda-Derecha¶

    El LED virtual muestra el balance izquierda-derecha de la potencia de pedaleo actual. Cada LED representa 5% de desplazamiento hacia un lado. La tabla usa pedaleo orientado hacia la derecha como ejemplo, lo opuesto sigue el mismo principio.

    Además, se mostrará un estado de error cuando el valor de balance izquierda-derecha recibido sea 100-0 o 0-100. Esta situación generalmente es causada por la desconexión de un lado del medidor de potencia bilateral o por fuerza momentánea durante el primer pedaleo.

    Ejemplo I - D
    50% - 50%
    45~50% - 50~55% (55% no incluido)
    40~45% - 55~60% (60% no incluido)
    ≤40% - ≥60%
    0%-100% (o 100%-0%)

    Igual que lo anterior.

    X Guía de Configuración¶

    Esta sección explica la función y el alcance de cada configuración en el orden de la página de configuración. Los números en los recuadros de título corresponden a la posición de cada elemento en la página de configuración.

    Para los números de campo mencionados en el alcance, consulte las explicaciones de cada campo anterior.

    ActivationCode (Código de Activación)¶

    Ingrese el código de activación en la página de configuración para desbloquear todas las funciones.

    Función:

    • Ingrese el código de activación que recibió después de la compra para activar todas las funciones de MyGahoo Pro

    Sugerencias de Configuración:

    • El código de activación está vinculado al dispositivo, y cada dispositivo requiere un código de activación separado
    • Si inicia sesión en una cuenta diferente en el mismo dispositivo, el código de activación no cambiará
    • Si reemplaza su dispositivo, necesita obtener un nuevo código de activación

    [1.1] FTP (Vatios)¶

    FTP es el valor de potencia crítica que un ciclista puede mantener a largo plazo, y es un parámetro fundamental para calcular múltiples métricas de entrenamiento.

    Función:

    • Establecer la potencia de umbral funcional del ciclista, utilizada para calcular zonas de potencia, relación potencia-peso, NP, TSS, IF y otras métricas de entrenamiento

    Alcance:

    • División de color de zona para el campo de potencia actual
    • Cálculo del campo de relación potencia-peso
    • Cálculo de TSS relacionado con el campo NP
    • Cálculo del campo IF

    Sugerencias de Configuración:

    • Se recomienda usar la potencia medida de 20 minutos o CP (Potencia Crítica) como valor de entrada
    • FTP necesita usarse con el peso en el perfil de Garmin para calcular la relación potencia-peso
    • Después de modificar FTP, métricas como TSS e IF se recalcularán basándose en los datos de NP grabados

    [1.2] Clave API de OpenWeather (ahora compatible con todos los dispositivos)¶

    Se usa para conectarse al servicio OpenWeather y obtener datos meteorológicos en tiempo real.

    Función:

    • Ingrese la clave API de OpenWeather para habilitar que la aplicación obtenga datos meteorológicos en línea

    Alcance:

    • Campo de temperatura del aire
    • Campo de temperatura sensación
    • Campo de humedad

    Sugerencias de Configuración:

    • Necesita registrarse y obtener una clave API en el sitio web oficial de OpenWeather usted mismo
    • El dispositivo necesita estar conectado a la red a través del teléfono
    • Se necesita adquirir ubicación GPS (es posible que no se puedan obtener datos meteorológicos en interiores)

    [1.3] Modo de Cambio de Página Virtual¶

    Controla cómo los usuarios cambian entre diferentes posiciones de bloques de datos en el diseño seleccionado.

    Función:

    • Establecer si habilitar el cambio virtual de página, y si usar botones u operaciones táctiles

    Sugerencias de Configuración:

    • Apagado: Desactivar cambio virtual de página, tocar la pantalla invocará el menú nativo del sistema
    • Modo de Botón Rápido: Presionar continuamente la combinación de botones "arriba abajo arriba abajo" (dentro de 2 segundos) para avanzar, solo soporta avanzar
    • Modo Táctil: Tocar el lado izquierdo de la mitad inferior de la pantalla para avanzar, el lado derecho para retroceder, adecuado para dispositivos táctiles
    • Modo Táctil y Botón Rápido: Habilitar ambos modos táctil y de botón simultáneamente

    [2.10] [W'Bal] CP (W) / W' (J) / Modo de Visualización / Algoritmo¶

    Este grupo de configuraciones controla en conjunto el cálculo y la visualización de la función W'Balance.

    CP (Potencia Crítica)¶

    El límite superior de potencia que un ciclista puede mantener a largo plazo, y también el umbral para el juicio de agotamiento/recuperación de W'Balance.

    Función:

    • Juicio de agotamiento/recuperación del campo W'Balance
    • Cuando la potencia es superior a CP, W'Balance se agota; cuando es inferior a CP, W'Balance se recupera

    Sugerencias de Configuración:

    • Si conoces tu CP, configúralo en CP; si no lo conoces, puedes aproximarlo a FTP

    WPRIME (Reserva de Energía W')¶

    La energía total que un ciclista puede输出的 por encima de CP.

    Sugerencias de Configuración:

    • El valor predeterminado es aproximadamente 10.000 julios (10 kilojulios)
    • Los ciclistas experimentados generalmente lo establecen en el rango de 15.000~20.000 julios

    Modo de Visualización¶

    Establece cómo se muestran los datos de W'Balance.

    Función:

    • Elegir si mostrar como porcentaje o kilojulios, y si incluir colores

    Sugerencias de Configuración:

    • Porcentaje: Mostrar porcentaje restante, con colores (verde=recuperación, rojo=agotamiento)
    • Kilojulios: Mostrar valor de energía restante, con colores
    • Porcentaje (Sin Color): Mostrar porcentaje restante, sin colores
    • Kilojulios (Sin Color): Mostrar valor de energía restante, sin colores

    Algoritmo¶

    Selecciona el modelo de cálculo para W'Balance.

    Sugerencias de Configuración:

    • Algoritmo Integral: El agotamiento y la recuperación son más lentos y suaves, adecuados para ciclismo de resistencia
    • Algoritmo Diferencial: Agotamiento rápido, recuperación rápida y más receptivo, adecuado para entrenamiento por intervalos

    [3.1-3.4] LED Izquierda / LED Derecha / LED Superior / LED Inferior¶

    Los LEDs virtuales se pueden configurar en los cuatro bordes de la pantalla, para mostrar diferentes tipos de datos.

    Función:

    • Mostrar zonas de potencia/velocidad, indicadores promedios, balance izquierda-derecha o barras de estado en los bordes de la pantalla

    Alcance:

    • LED de zona de potencia: Afecta la visualización de zona de la potencia actual y varios campos de potencia promedio
    • LED de zona de frecuencia cardíaca: Afecta la visualización de zona del campo de frecuencia cardíaca actual
    • LED de indicador promedio: Afecta la visualización de adelanto/retraso de los datos promedios
    • LED de balance izquierda-derecha: Afecta la visualización del campo de balance izquierda-derecha
    • LED de barra de estado: Muestra iconos de estado como batería, GPS, conexión Bluetooth, hora, etc.

    Descripción de Configuración:

    Posición Contenido Seleccionable
    LED Izquierda (3.1) Apagado / Zona de Potencia de 3 Segundos / Zona de Potencia / Zona de Frecuencia Cardíaca / Indicador de Velocidad Promedio / Indicador de Potencia Promedio
    LED Derecha (3.2) Apagado / Zona de Potencia de 3 Segundos / Zona de Potencia / Zona de Frecuencia Cardíaca / Indicador de Velocidad Promedio / Indicador de Potencia Promedio
    LED Superior (3.3) Apagado / Barra de Estado / Zona de Potencia de 3 Segundos / Zona de Potencia / Zona de Frecuencia Cardíaca / Indicador de Velocidad Promedio / Indicador de Potencia Promedio / Balance de Potencia Izquierda-Derecha / Balance Izquierda-Derecha de 3 Segundos
    LED Inferior (3.4) Apagado / Barra de Estado / Zona de Potencia de 3 Segundos / Zona de Potencia / Zona de Frecuencia Cardíaca / Indicador de Velocidad Promedio / Indicador de Potencia Promedio / Balance de Potencia Izquierda-Derecha / Balance Izquierda-Derecha de 3 Segundos

    Sugerencias de Configuración:

    • Apagado: No se muestra LED en este borde
    • Barra de Estado: Solo disponible para superior e inferior, muestra icono de batería, estado de señal GPS, estado de conexión telefónica, cantidad de mensajes no leídos, hora actual
    • Zona de Potencia/Frecuencia Cardíaca: 7 LEDs muestran la distribución de cantidad para cada zona de potencia/frecuencia cardíaca
    • Indicador Promedio: Azul significa adelanto, rojo significa retraso
    • Balance Izquierda-Derecha: Dedicado para LEDs superior e inferior, cada LED representa 5% de desplazamiento hacia un lado

    Estado de Error de LED de Balance Izquierda-Derecha

    Si el valor de balance izquierda-derecha muestra 100-0 o 0-100, se mostrará un estado de error. Esto suele ser causado por la desconexión de un lado del medidor de potencia bilateral o fuerza momentánea durante el primer pedaleo.

    Habilitar Páginas¶

    Controla si se habilitan la Página 2 y la Página 3.

    Alcance:

    • Si la función de cambio de página está disponible
    • Número de página no mostrado en modo de página única

    Sugerencias de Configuración:

    La configuración de múltiples páginas permite a los usuarios configurar múltiples conjuntos de diferentes combinaciones de bloques de datos, cada conjunto usando el mismo estilo de diseño pero mostrando diferentes bloques de datos.
