    モジュール紹介¶

    I リアルタイム監視データ¶

    1. 現在のパワー¶

    リアルタイムのライディングパワー出力を表示します。

    色

    これは背景色を表示できるモジュールです。ConnectIQアプリで2つの色シーケンススタイルを選択できます。ただし、ユーザーは個別の色やゾーン範囲をカスタマイズできません。

    • Garminスタイル：グレー-ブルー-グリーン-イエロー-オレンジ-レッド-パープル（ゾーン1～ゾーン7）
    • Wahooスタイル：グレー-ダークブルー-ライトブルー-グリーン-イエロー-オレンジ-レッド（ゾーン1～ゾーン7）

    平均パワーインジケーター¶

    これはオン/オフできる設定で、現在のパワークラス内で現在のパワーと平均功率を比較するために使用されます。ConnectIQアプリで設定できます。「矢印」表示モードをサポートしています。

    • 「矢印」
      • 上向き：平均功率より高い
      • 下向き：平均功率より低い
      • 表示なし：平均功率と等しい、またはライディング未開始


    2. 現在の速度¶

    現在のライディング速度を表示します。単位はユーザーのGarmin Connectの設定と一致します（kph/mph）。

    平均速度インジケーター¶

    これはオン/オフできる設定で、現在の速度モジュール内で現在の速度と平均速度を比較するために使用されます。ConnectIQアプリで設定できます。「矢印」と「背景」の2つの表示モードがあります。

    • 「矢印」
      • 上向き：平均速度より高い
      • 下向き：平均速度より低い
      • 表示なし：平均速度と等しい、またはライディング未開始
    • 「背景」
      • 赤色：平均速度より低い
      • 緑色：平均速度より高い


    3. 現在の心拍数¶

    リアルタイムの心拍数データを表示します。

    色

    これは背景色を設定できるモジュールです。ConnectIQアプリで2つの色シーケンススタイルを選択できます。ただし、ユーザーは個別の色やゾーン範囲をカスタマイズできません。

    • Garminスタイル：グレー-グレー-ブルー-グリーン-イエロー-レッド（<ゾーン1、ゾーン1～ゾーン5）
    • Wahooスタイル：グレー-ブルー-グリーン-イエロー-オレンジ-レッド（<ゾーン1、ゾーン1～ゾーン5）

    平均心拍数インジケーター¶

    これはオン/オフできる設定で、現在心拍数モジュール内で現在心拍数と平均心拍数を比較するために使用されます。ConnectIQアプリで設定できます。「矢印」表示モードをサポートしています。

    • 「矢印」
      • 上向き：平均心拍数より高い
      • 下向き：平均心拍数より低い
      • 表示なし：平均心拍数と等しい、またはライディング未開始


    4. 現在のケイデンス¶

    リアルタイムのケイデンス値を表示します。

    平均ケイデンスインジケーター¶

    これはオン/オフできる設定で、現在ケイデンスモジュール内で現在ケイデンスと平均ケイデンスを比較するために使用されます。ConnectIQアプリで設定できます。「矢印」表示モードをサポートしています。

    • 「矢印」
      • 上向き：平均ケイデンスより高い
      • 下向き：平均ケイデンスより低い
      • 表示なし：平均ケイデンスと等しい、またはライディング未開始


    5. 現在の標高¶

    現在の標高を表示します。単位はユーザーのGarmin Connectの設定と一致します（m/ft）。


    6. 現在の勾配*¶

    現在の勾配を表示します。
    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります

    色

    これは背景色を表示できるモジュールです。色は対応する勾配に応じて変化しますが、ユーザーは色や勾配範囲をカスタマイズできません。

    例
    勾配範囲 < 0.5% 0.5%~3.99% 4%~7.99% 8%~11.99% 12%~19.99% > 20%

    35. NP™（正規化パワー）*¶

    現在のアクティビティの正規化パワーを表示します。

    データ損失リスク

    アクティビティ中にMyGahooフィールドを「再追加」したり、他のライディングモードに入ると、このモジュールのデータがクリアされます。（ただし、Garmin自体が記録するアクティビティは影響を受けず、MyGahooのみがゼロからこれらのデータの蓄積を再開します）。

    ™正規化パワー（NP）およびトレーニングストレススコア（TSS）は、Peaksware, LLCの登録商標です。
    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります


    36. TSS™（トレーニングストレススコア）*¶

    現在のアクティビティのトレーニングストレススコアを表示します。

    データ損失リスク

    アクティビティ中にMyGahooフィールドを「再追加」したり、他のライディングモードに入った後に現在のモードに戻ったりすると、このモジュールのデータがクリアされます。（ただし、Garmin自体が記録するアクティビティは影響を受けず、MyGahooのみがゼロからこれらのデータの蓄積を再開します）。

    ™正規化パワー（NP）およびトレーニングストレススコア（TSS）は、Peaksware, LLCの登録商標です。
    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります

    37. W'Balance*¶

    現在のアクティビティのW'Balance（W prime balance）を表示します。これが機能するには、CP（クリティカルパワー）とW'（W Prime）を事前に定義する必要があります。科学的説明については、それが何であるかを説明する多くの記事やビデオがあります。

    アクティビティ中、このフィールドは緑色または赤色になります。緑色の場合、現在のパワーがCPより低いことを示し、言い換えれば「回復」していることを意味します。逆に、赤色の場合は消耗していることを示します。

    現在の数学モデルはFroncioni / Clarkeの微分モデルを使用しています：

    W′bal = W′bal + (CP - P) * (W′ - W′bal) / W′ when P > CP

    W′bal = W′bal + (CP - P) when P < CP

    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります


    38. 現在のトレーニングステップ残り時間¶

    現在のトレーニングセッションステップのカウントダウン残り時間を表示します。Garmin構造化トレーニング（ワークアウト）が開始されている場合にのみ有効です。現在のトレーニングステップに時間制限がない場合は、データは表示されません。



    39. IF™（強度係数）*¶

    現在のアクティビティの強度係数を表示します。このトレーニングセッションの強度レベルを評価するために使用されます。

    ™強度係数（IF）はPeaksware, LLCの登録商標です。

    46. 予想到着時刻*¶

    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります

    50. 心拍ゾーンヒストグラム*¶

    データ損失リスク

    アクティビティ中にMyGahooフィールドを「再追加」したり、他のライディングモードに入った後に現在のモードに戻ったりすると、このモジュールのデータがクリアされます。（ただし、Garmin自体が記録するアクティビティは影響を受けず、MyGahooのみがゼロからこれらのデータの蓄積を再開します）。

    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります


    51. ペダリング効率¶

    現在の左右ペダルのトルク効率をパーセンテージで表示します。このデータインターフェースをサポートしているパワーメーターが必要です。

    • 形式：左% / 右%
    • パワーク Luciaがサイド별データをサポートしていない場合は、複合値のみが表示されます


    52. スムースネス¶

    現在の左右ペダルのペダリングスムースネスをパーセンテージで表示します。このデータインターフェースをサポートしているパワーメーターが必要です。

    • 形式：左% / 右%
    • パワーク Luciaが複合データのみをサポートしている場合（左右区別なし）は、複合値のみが表示されます

    56. 風*¶

    現在の風速と相対/絶対風向を表示します。

    *Garmin公式はデータインターフェースを提供していないため、計算されたデータは不正確または間違う可能性があります

    風速単位¶

    • m/s：メートル/秒
    • KPH：キロメートル/時
    • MPH：マイル/時
    • Beaufort scale：風力階級、0~12級

    風速レベル¶

    風速レベルは矢印の数で示され、異なる数に対応する風速は以下の図に示されています。選択した風速単位がm/sでない場合、矢印の数は表示される数字ではなく、正しい風速に基づいて計算されます。

    絶対/相対風向¶

    • 絶対風向：天気予報で与えられる風向で、ライディング方向とは無関係
    • 相対風向：現在のライディング方向と風向の相対角度。例えば、西に向かって走行し、絶対風向が北から南の場合、相対風向は右から左になります。

    風向の色¶

    相対風向を表示する際、矢印は風の角度に応じて色分けされます。赤色は向かい風（相対風が左前45°から右前45°）を示し、緑色は追い風（相対風が左後45°から右後45°）を示し、黒色は横風を示します。

    設定¶

    風モジュールは最適な表示効果を得るためにConnectIQアプリでの設定が必要です。詳細については天気設定モジュールを参照してください。


    57. 温度（OpenWeather）*¶

    58. 体感温度（OpenWeather）*¶

    59. 湿度（OpenWeather）*¶

    60. 日の出時間¶

    61. 日の入り時間¶

    IX バーチャルLED¶

    バーチャルLEDは画面の端の周りに設定できます。ユーザーは異なる位置のLEDを使用して異なる情報を表示できます。

    バーチャルLEDの2つの水平フィールド（上と下）は現在ステータスバーをサポートしています。ステータスバーのアイコンは左から右に：バッテリー、GPS信号状態、电话接続状態（条件付き）、未読メッセージ（条件付き）、時刻です。

    電話がGarmin Edgeに接続されていない場合、「Bluetooth」アイコンは表示されません。未読メッセージがない場合、未読メッセージアイコンは表示されません。未読メッセージ数が9を超える場合、実際の数字ではなく常に「9+」が表示されます。

    画像 状態 説明
    QUALITY_NOT_AVAILABLE GPS利用不可
    QUALITY_LAST_KNOWN 最後に知られたGPS位置に基づく位置
    QUALITY_POOR 貧弱なGPS位置計算による位置。2-D GPS位置のみ利用可能、追跡衛星数の制限による可能रण성
    QUALITY_USABLE 使用可能なGPS位置計算による位置。3-D GPS位置利用可能、境界HDOP（水平精度劣化）あり
    QUALITY_GOOD 良好なGPS位置計算による位置。3-D GPS位置利用可能、良好から優秀なHDOP（水平精度劣化）あり

    このセクションでは、設定ページの順序で各設定の機能と影響範囲説明します。タイトルボックス内の番号は、 해당항목が設定ページ内で位置に対応します。

    ActivationCode（アクティブコード）¶

    設定ページでアクティブコードを入力して、すべての機能をアンロックします。

    機能：

    • 購入後に受け取ったアクティブコードを入力して、すべてのMyGahoo Pro機能をアクティブ化します

    設定の提案：

    • アクティブコードはデバイスにバインド되어おり、各デバイスには個別のアクティブコードが必要です
    • 同じデバイスで異なるアカウントにログインする場合、アクティブコードは変更されません
    • デバイスを交換する場合は、新しいアクティブコードを取得する必要があります

    [1.1] FTP（ワット）¶

    FTPはサイクリストが長時間維持できる臨界パワー値であり、複数のトレーニング指標を計算するための基本パラメータです。

    機能：

    • 功率ゾーン、パワーウェイトレシオ、NP、TSS、IFなどのトレーニング指標を計算するために使用されるサイクリストの機能的閾値パワーを設定します

    影響範囲：

    • 現在功率フィールドのゾーン颜色划分
    • パワーウェイトレシオフィールドの計算
    • NPフィールドに関連するTSS計算
    • IFフィールドの計算

    設定の提案：

    • 20分測定功率またはCP（臨界パワー）を入力値として使用することをお勧めします
    • パワーウェイトレシオを計算するには、FTPはGarminプロフィール内の体重と一緒に使用する必要があります
    • FTPを変更すると、TSS、IFなどの指標は記録されたNPデータに基づいて再計算されます

    [1.2] OpenWeather APIキー（すべてのデバイスでサポート）¶

    OpenWeatherサービスに接続してリアルタイムの天気データを取得するために使用されます。

    機能：

    • アプリケーションがオンライン天気データを取得できるようにOpenWeather APIキーを入力します

    影響範囲：

    • 気温フィールド
    • 体感温度フィールド
    • 湿度フィールド

    設定の提案：

    • OpenWeatherの公式Webサイトで自分で登録してAPIキーを取得する必要があります
    • デバイスは電話を通じてネットワークに接続する必要があります
    • GPS位置を取得する必要があります（屋内では天気データを取得できない場合があります）

    [1.3] 仮想ページスクロールモード**¶

    選択したレイアウト内で異なるデータブロック位置間をユーザーがどのように切り替えかを制御します。

    機能：

    • 仮想スクロールを有効にするかどうか、およびボタン还是触摸操作を使用するか設定します

    設定の提案：

    • オフ：仮想スクロールを無効化し、画面に触れるとシステムネイティブメニューが呼び出されます
    • クイックボタン режим：連続して「上下上下」ボタンの組み合わせ（2秒以内）を押して後ろにスクロールし、後ろへのスクロールのみをサポートします
    • タッチモード：画面下半分の左側をタップして右にスクロールし、右側をタップして左にスクロールし、タッチスクリーンデバイスに適しています
    • タッチ・アンド・クイックボタン режим：触摸とボタンの両方のモードを同時に有効にします

    [2.10] [W'Bal] CP (W) / W' (J) / 表示モード / 算法**¶

    この設定グループがW'Balance機能の計算と表示を jointly制御します。

    CP（臨界パワー）¶

    サイクリストが長時間維持できる功率の上限，也是W'Balance消耗/回復判断の閾値です。

    機能：

    • W'Balance字段の消耗/回復判断
    • 功率がCPより高い時はW'Balanceが消耗し、CPより低い時はW'Balanceが回復します

    設定の提案：

    • CPを明知っている場合はCPに設定し、如果不知道则可近似设置为FTP

    WPRIME（W'能量储备）¶

    サイクリストがCP以上を出力できる总能量储备。

    設定の提案：

    • デフォルト値は約10000焦耳（10千焦）です
    • 経験豊富なサイクリストは通常15000~20000焦耳の範囲に設定します

    表示モード**¶

    W'Balanceデータの表示方法を設定します。

    機能：

    • パーセンテージ还是千焦耳で表示するか、色を含むかを選択できます

    設定の提案：

    • パーセンテージ：残りのパーセンテージを表示、色付き（緑色=回復、赤色=消耗）
    • 千焦：残りのエネルギー値を表示、色付き
    • パーセンテージ（色なし）：残りのパーセンテージを表示、色なし
    • 千焦（色なし）：残りのエネルギー値を表示、色なし

    算法**¶

    W'Balanceの計算モデル選擇します。

    設定の提案：

    • 積分算法：消耗と回復がどちらもより遅く、よりスムーズで、耐久ライディングに適しています
    • 微分算法：消耗が速く、回復も速く、より敏感で、間隔トレーニングに適しています

    • 功率ゾーンLED：現在功率和各种平均功率字段のゾーン可視化に影響します
    • 心拍数ゾーンLED：現在心拍数字段のゾーン可視化に影響します
    • 平均インジケーターLED：平均データの先行/遅れ表示に影響します
    • 左右バランスLED：左右バランス字段の可視化に影響します
    • ステータスバーLED：バッテリー、GPS、蓝牙连接、时间などのステータスアイコンを表示します

    設定の説明：

    位置 選択可能な内容
    左LED（3.1） オフ / 3秒功率ゾーン / 功率ゾーン / 心拍数ゾーン / 平均速度インジケーター / 平均功率インジケーター
    右LED（3.2） オフ / 3秒功率ゾーン / 功率ゾーン / 心拍数ゾーン / 平均速度インジケーター / 平均功率インジケーター
    上LED（3.3） オフ / ステータスバー / 3秒功率ゾーン / 功率ゾーン / 心拍数ゾーン / 平均速度インジケーター / 平均功率インジケーター / 左右功率バランス / 3秒左右バランス
    下LED（3.4） オフ / ステータスバー / 3秒功率ゾーン / 功率ゾーン / 心拍数ゾーン / 平均速度インジケーター / 平均功率インジケーター / 左右功率バランス / 3秒左右バランス

    設定の提案：

    • オフ：この边缘にLEDを表示しません
    • ステータスバー：上と下にのみ利用可能で、バッテリーアイコン、GPS信号状態、电话接続状態、未読メッセージ数、現在時間を表示します
    • 功率/心拍数ゾーン：7つのLEDが各功率/心拍数ゾーンの數量分布を表示します
    • 平均インジケーター：蓝色は先行、红色は遅れを示します
    • 左右バランス：上と下のLED专用で、各LEDは片側5%のオフセットを表します

    左右バランスLEDエラー状態

    左右バランス値が100-0または0-100を表示している場合、エラー状態が表示されます。これは通常、両側パワーメーターの片側が切断された거나最初のペダリング時の瞬間的な力によって発生します。

    ページを有効にする**¶

    第2ページと第3頁を有効にするかどうか控制します。

    影響範囲：

    • ページ切り替え機能が利用可能かどうか
    • 単一ページモードではページ番号が表示されません

    設定の提案：

    • 第1頁は常に有効でオフにできません
    • 複数のページを有効にすると、ユーザーは仮想スクロールまたは触摸操作でページを切り替えできます
    • 各ページは独立してMainBlockと左右のデータブロックタイプを設定できます

    ページとレイアウトの関係

    複数ページ設定を使用すると、ユーザーは複数の異なるデータブロック组合を構成でき、各组合は同じレイアウトスタイルを使用하지만異なるデータブロックを表示します。
