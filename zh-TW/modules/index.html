    模組介紹¶

    I 即時監控數據¶

    1. 當前功率¶

    顯示自行車的即時功率輸出。

    顏色

    這是一個可以顯示背景顏色的模組。您可以在ConnectIQ應用程式中選擇兩種顏色序列。但是，使用者無法自訂單個顏色或區間範圍。

    • Garmin風格：灰-藍-綠-黃-橙-紅-紫（區間1~區間7）
    • Wahoo風格：灰-深藍-淺藍-綠-黃-橙-紅（區間1~區間7）

    平均功率指示器¶

    這是一個開/關參數，用於在當前功率模組中比較當前功率與平均功率。可以在ConnectIQ應用程式中配置。支援「箭頭」顯示模式。

    • 「箭頭」
      • 向上：高於平均功率
      • 向下：低於平均功率
      • 不顯示：等於平均功率或騎行未開始


    2. 當前速度¶

    顯示自行車的當前速度。單位與您在Garmin Connect中的設定一致（kph/mph）。

    平均速度指示器¶

    這是一個開/關參數，用於在當前速度模組中比較當前速度與平均速度。可以在ConnectIQ應用程式中配置。有兩種顯示模式：「箭頭」和「背景」。

    • 「箭頭」
      • 向上：高於平均速度
      • 向下：低於平均速度
      • 不顯示：等於平均速度或騎行未開始
    • 「背景」
      • 紅色：低於平均速度
      • 綠色：高於平均速度


    3. 當前心率¶

    顯示即時心率數據。

    顏色

    這是一個可以設定背景顏色的模組。您可以在ConnectIQ應用程式中選擇兩種顏色序列。但是，使用者無法自訂單個顏色或區間範圍。

    • Garmin風格：灰-灰-藍-綠-黃-紅（<區間1，區間1~區間5）
    • Wahoo風格：灰-藍-綠-黃-橙-紅（<區間1，區間1~區間5）

    平均心率指示器¶

    這是一個開/關參數，用於在當前心率模組中比較當前心率與平均心率。可以在ConnectIQ應用程式中配置。支援「箭頭」顯示模式。

    • 「箭頭」
      • 向上：高於平均心率
      • 向下：低於平均心率
      • 不顯示：等於平均心率或騎行未開始


    4. 當前踏頻¶

    顯示即時踏頻值。

    平均踏頻指示器¶

    這是一個開/關參數，用於在當前踏頻模組中比較當前踏頻與平均踏頻。可以在ConnectIQ應用程式中配置。支援「箭頭」顯示模式。

    5. 當前海拔¶

    6. 當前坡度*¶

    顯示當前坡度。
    *由於Garmin未正式提供數據介面，計算的數據可能不準確或錯誤

    顏色

    這是一個可以顯示背景顏色的模組。顏色根據對應的坡度變化，但使用者無法自訂顏色或坡度範圍。

    37. W'Balance*¶

    顯示當前活動的W'Balance（W Prime Balance）。這需要預先定義CP（臨界功率）和W'（W Prime）才能工作。有關科學解釋，會有大量文章或視頻來解釋它是什麼。

    在活動期間，此字段可以是綠色或紅色。當為綠色時，表示您當前的功率低於CP，換句話說，您正在「恢復」。反之，當為紅色時，表示您正在消耗。

    當前的數學模型使用Froncioni / Clarke的微分模型：

    W′bal = W′bal + (CP - P) * (W′ - W′bal) / W′ 當 P > CP

    W′bal = W′bal + (CP - P) 當 P < CP

    *由於Garmin未正式提供數據介面，計算的數據可能不準確或錯誤

    *由於Garmin未正式提供數據介面，計算的數據可能不準確或錯誤

    風速單位¶

    • m/s：公尺/秒
    • KPH：公里/小時
    • MPH：英里/小時
    • Beaufort scale：風力等級，0~12級

    風速等級¶

    風速等級由箭頭數量指示，不同數量對應的風速如下图所示。當選擇的風速單位不是m/s時，箭頭數量仍將根據正確的風速而非顯示的數字進行計算。

    絕對/相對風向¶

    • 絕對風向：天氣預報中給出的風向，與騎行方向無關
    • 相對風向：當前騎行方向與風向的相對角度。例如，如果向西行駛，絕對風向從北向南，則相對風向從右向左。

    風向顏色¶

    顯示相對風向時，箭頭根據風角度著色。紅色表示逆風（相對風從左前45°到右前45°）；綠色表示順風（相對風從左後45°到右後45°）；黑色表示側風。

    配置¶

    風模組需要在ConnectIQ應用程式中配置以獲得最佳顯示效果。詳情請參閱天氣配置模組。


    57. 溫度（OpenWeather）*¶

    顯示當前溫度，以攝氏度或華氏度顯示。數據來源為OpenWeather，因此需要配置有效的OpenWeather API才能啟用數據。


    58. 體感溫度（OpenWeather）*¶

    顯示當前體感溫度，以攝氏度或華氏度顯示。數據來源為OpenWeather，因此需要配置有效的OpenWeather API才能啟用數據。


    59. 濕度（OpenWeather）*¶

    顯示當前相對濕度，以百分比顯示。數據來源為OpenWeather，因此需要配置有效的OpenWeather API才能啟用數據。


    60. 日出時間¶

    顯示當天的日出時間。數據來源為Garmin內置天氣服務，需要設備支援天氣功能（530/830及更新型號）且已獲取GPS定位。


    61. 日落時間¶

    顯示當天的日落時間。數據來源為Garmin內置天氣服務，需要設備支援天氣功能（530/830及更新型號）且已獲取GPS定位。


    IX 虛擬LED¶

    虛擬LED可以配置在螢幕邊緣周圍。使用者可以使用不同位置的LED來顯示不同的資訊。

    虛擬LED的兩個水平欄位（上和下）現在支援狀態列。狀態列圖示從左到右分別是：電池、GPS信號狀態、手機連接狀態（條件性）、未讀訊息（條件性）、時間。

    當手機未連接到Garmin Edge時，「藍牙」圖示將不顯示。當沒有未讀訊息時，未讀訊息圖示將不顯示。當未讀訊息數量大於9時，將始終顯示「9+」而不是實際數字。

    圖片 狀態 描述
    QUALITY_NOT_AVAILABLE GPS不可用
    QUALITY_LAST_KNOWN 基於最後已知GPS位置的位置
    QUALITY_POOR 來自差GPS位置計算的位置。僅提供2-D GPS位置，可能由於追蹤的衛星數量有限
    QUALITY_USABLE 來自可用GPS位置計算的位置。提供3-D GPS位置，具有邊際HDOP（水平精度稀釋）
    QUALITY_GOOD 來自良好GPS位置計算的位置。提供3-D GPS位置，具有良好到優秀的HDOP（水平精度稀釋）

    X 配置說明¶

    本章節按設定頁的順序，逐項說明每個設定的作用與影響範圍。標題方框內的編號對應該項在設定頁中的位置。

    影響範圍中涉及的字段編號，請參閱前述各字段的說明。

    ActivationCode（啟動碼）¶

    在設定頁中輸入啟動碼以解鎖完整功能。

    作用：

    • 輸入您購買後收到的啟動碼，啟動 MyGahoo Pro 全部功能

    配置建議：

    • 啟動碼與設備綁定，每個設備需要獨立的啟動碼
    • 如果在同一個設備上登入不同的帳號，啟動碼不會改變
    • 如果更換設備，需要重新獲取啟動碼

    [1.1] FTP（瓦）¶

    FTP 是騎手可以長期維持的臨界功率值，是計算多項訓練指標的基礎參數。

    作用：

    • 設定騎手的功能性閾值功率，用於計算功率區間、功重比、NP、TSS、IF 等訓練指標

    影響範圍：

    • 當前功率字段的區間顏色劃分
    • 功重比字段的計算
    • NP字段相關的 TSS 計算
    • IF字段的計算

    配置建議：

    • 建議使用 20 分鐘實測功率或 CP（臨界功率）作為輸入值
    • FTP 需要與 Garmin 個人資料中的體重配合使用來計算功重比
    • 修改 FTP 後，TSS、IF 等指標會基於已記錄的 NP 數據重新計算

    [1.2] OpenWeather API金鑰（現在支援所有設備）¶

    用於連接 OpenWeather 服務，獲取即時天氣數據。

    作用：

    • 輸入 OpenWeather API 金鑰，使應用能夠獲取線上天氣數據

    影響範圍：

    • 空氣溫度字段
    • 體感溫度字段
    • 濕度字段

    配置建議：

    • 需要自行在 OpenWeather 官網註冊並獲取 API 金鑰
    • 設備需要通過手機連接網路
    • 需要已獲取 GPS 定位（室內可能無法獲取天氣數據）

    [1.3] 虛擬頁面翻頁模式**¶

    控制使用者如何在已選擇的佈局中切換不同的數據塊位置。

    作用：

    • 設定是否啟用虛擬翻頁功能，以及使用按鈕還是觸控操作

    配置建議：

    • 關閉：禁用虛擬翻頁，觸控螢幕會喚起系統原生選單
    • 快速按鈕模式：連續按動「上下上下」按鈕組合（間隔 2 秒內）向後翻頁，僅支援向後翻頁
    • 觸控模式：點擊螢幕下半部分左側向右翻頁，右側向左翻頁，適用於觸控螢幕設備
    • 觸控和快速按鈕模式：同時啟用觸控和按鈕兩種模式

    [2.10] [W'Bal] CP (W) / W' (J) / 顯示模式 / 算法**¶

    這組設定共同控制 W'Balance 功能的計算和顯示。

    CP（臨界功率）¶

    騎手可以長時間維持的功率上限，也是 W'Balance 消耗/恢復的判定閾值。

    作用：

    • W'Balance字段的消耗/恢復判定
    • 當功率高於 CP 時消耗 W'Balance，低於 CP 時恢復 W'Balance

    配置建議：

    • 如果您明確知道自己的CP則設定為CP，如果不知道則可以近似設定為FTP

    WPRIME（W'能量儲備）¶

    騎手可以在 CP 以上輸出的總能量儲備。

    配置建議：

    • 默認值約為 10000 焦耳（10 千焦）
    • 有經驗的騎手通常設定在 15000~20000 焦耳範圍

    顯示模式**¶

    設定 W'Balance 數據的顯示方式。

    作用：

    • 選擇以百分比還是千焦耳顯示，以及是否帶顏色

    配置建議：

    • 百分比：顯示剩餘百分比，帶顏色（綠色=恢復，紅色=消耗）
    • 千焦：顯示剩餘能量值，帶顏色
    • 百分比（無顏色）：顯示剩餘百分比，無顏色
    • 千焦（無顏色）：顯示剩餘能量值，無顏色

    算法**¶

    選擇 W'Balance 的計算模型。

    配置建議：

    • 積分算法：消耗和恢復都較慢、更平滑，適合耐力騎行
    • 微分算法：消耗快、恢復也快，響應更不及時，適合間歇訓練

    [2.11] 啟用右上標題偏移（避免雷達圖示重疊）**¶

    設定右上角標題是否向右偏移，避免與雷達圖示重疊。

    配置建議：

    • 預設關閉即可

    設定齒比圖是否顯示為 1X 單盤模式。

    配置建議：

    • 開啟後：齒比圖將僅顯示飛輪圖表，而不顯示牙盤圖表
    • 關閉後：預設同時顯示飛輪和牙盤圖表

    [3.1-3.4] 左LED / 右LED / 上LED / 下LED**¶

    虛擬 LED 可以配置在螢幕的四條邊緣，用於顯示不同類型的數據。

    作用：

    • 在螢幕邊緣顯示功率/區間、平均指示器、左右平衡或狀態列

    影響範圍：

    • 功率區間 LED：影響當前功率、各平均功率字段的區間視覺化
    • 心率區間 LED：影響當前心率字段的區間視覺化
    • 平均指示器 LED：影響平均數據的領先/落後顯示
    • 左右平衡 LED：影響左右平衡字段的視覺化
    • 狀態列 LED：顯示電池、GPS、藍牙連接、時間等狀態圖示

    配置說明：

    位置 可選擇的內容
    左側 LED（3.1） 關閉 / 3秒功率區間 / 功率區間 / 心率區間 / 平均速度指示器 / 平均功率指示器
    右側 LED（3.2） 關閉 / 3秒功率區間 / 功率區間 / 心率區間 / 平均速度指示器 / 平均功率指示器
    頂部 LED（3.3） 關閉 / 狀態列 / 3秒功率區間 / 功率區間 / 心率區間 / 平均速度指示器 / 平均功率指示器 / 左右功率平衡 / 3秒左右平衡
    底部 LED（3.4） 關閉 / 狀態列 / 3秒功率區間 / 功率區間 / 心率區間 / 平均速度指示器 / 平均功率指示器 / 左右功率平衡 / 3秒左右平衡

    配置建議：

    • 關閉：該邊不顯示 LED
    • 狀態列：僅頂部和底部可用，顯示電池圖示、GPS 信號狀態、手機連接狀態、未讀訊息數量、當前時間
    • 功率/心率區間：7 個 LED 顯示各功率/心率區間的數量分布
    • 平均指示器：藍色表示領先，紅色表示落後
    • 左右平衡：頂部和底部 LED 專用，每個 LED 代表一側 5% 的偏移

    左右平衡 LED 錯誤狀態

    如果左右平衡值顯示為 100-0 或 0-100，將顯示錯誤狀態。這通常是由於雙側功率計的一側斷開連接或首次踩踏時的瞬間力量導致的。

    啟用頁面**¶

    控制是否啟用第 2 頁和第 3 頁。

    影響範圍：

    • 頁面切換功能是否可用
    • 單頁模式下不顯示頁碼

    配置建議：

    • 第 1 頁始終啟用且不可關閉
    • 啟用多頁後，使用者可以通過虛擬滾動或觸控操作切換頁面
    • 每個頁面可獨立設定 MainBlock 和左右兩側的數據塊類型

    頁面與佈局的關係

    多頁面設定允許使用者配置多組不同的數據塊組合，每組使用相同的佈局樣式但選擇不同的數據塊顯示。
